# Quiz App Marathi

मराठी Quiz Web App — 100 प्रश्न, 5 विषय, 3 levels, timer आणि local leaderboard.

## GitHub Pages
Repository मध्ये `index.html`, `script.js`, `style.css` हे तीन files root मध्ये ठेवा आणि GitHub Pages ला `main` branch / root वरून publish करा.

## Monetization
ही आवृत्ती AdSense-ready structure देते, पण Google approval किंवा earnings ची हमी देत नाही. AdSense मंजुरीनंतर Google ने दिलेला अधिकृत ad code वापरा.

**महत्त्वाचे:** `index.html` मधील canonical URL आणि Contact email तुमच्या खऱ्या माहितीनुसार बदला.
